# Nubd Analytics — Data Engineering Learning Platform

Free, hands-on, interactive labs covering the full [Data Engineering Roadmap](https://roadmap.sh/data-engineer).
Each lab is a standalone HTML file — no frameworks, no sign-up, just open and learn.

**Live site:** https://amrgnegm.github.io/Nubd-Analytics

---

## Lab Format

Every lab uses a 3-tier interactive format:

| Tier | Purpose |
|------|---------|
| 📋 Task | What you need to build — always visible |
| 💡 Hint | Skeleton code with `_____` blanks |
| ✅ Answer | Full tested solution (collapsed by default) |

Plus: knowledge-check quizzes, step checkboxes, live progress bar, and a completion card.
